  • Function: Support the built‑in CPython sms extension module, enabling Python scripts to send, receive, and read SMS messages on the Device.
  • User Control: Not essential for core basic functions. You refuse during installation or first use. Refusal affects only the sms module.
  • Privacy: These permissions read SMS content, involving personal privacy data.
  • Liability Waiver: If you grant these permissions and use the sms module, all charges, privacy leaks, or legal liabilities are solely borne by you. The Developer assumes no responsibility.

3.2 Camera Permission (CAMERA)

  • Function: Support scanning QR codes to quickly download and install Python packages not yet included in the Application's built‑in package repository. By scanning package source URLs or PyPI links, you can conveniently add Third‑Party Libraries to your Python environment.
  • User Control: Not essential for core basic functions. You refuse during installation or first use. Refusal affects only the QR code scanning package download feature.
  • Privacy: This permission accesses the Device's camera hardware and captures images of QR codes. The captured content is used solely for parsing package download information. No images, photos, or video data are stored, uploaded, or shared with any Third Party.
  • Liability Waiver: You bear full responsibility for the legality, security, and compatibility of any Python packages downloaded via QR code scanning. The Developer does not audit, verify, or endorse Third‑Party packages. The Developer assumes no responsibility for any damages arising from the use of such packages.

3.3 Network Permissions (INTERNET / ACCESS_NETWORK_STATE)

  • Function: Enable network prompts (version updates, community content) and network request functionality in Python scripts.
  • User Control: Refusal prevents prompts from displaying and network‑requesting scripts from running.
  • Cost: Network use generates data traffic charges from your telecommunications carrier.

3.4 Install Apps Permission (REQUEST_INSTALL_PACKAGES)

  • Function: Reserved for the Application's future auto‑update functionality.
  • User Control: Currently not enabled. When enabled, the Developer notifies you via pop‑ups or update logs and installs Updates only with your explicit consent.
  • Security: The Developer pushes digitally signed update packages only through Official Channels.

3.5 WeChat Share SDK

  • Function: The Application integrates the WeChat Share SDK to enable sharing script code snippets, execution results, or application‑related content to WeChat Moments or WeChat Friends.
  • User Control: Sharing functionality is triggered solely by your explicit action (clicking the share button). The SDK does not automatically share any content.
